550W 综合指挥系统 · 部署教程

从零开始，把 550W 综合指挥系统部署到你的电脑上：只需一个浏览器和一个文本编辑器，复制一段 HTML 代码保存为文件，双击即可运行。本教程逐步讲解保存、打开、启用 Python、运行春节十二响与常见问题排查。

VERSION 1.0 · 单文件部署 · 无需服务器

一准备工作

PREPARATION

你需要两样东西：

  • 一个浏览器（推荐 Chrome 或 Edge，别用 IE）
  • 一个文本编辑器（Windows 用记事本，Mac 用文本编辑）
▶ 不想自己动手？在线直接体验

在线体验已由官网部署完毕，打开即用；如需部署到本地电脑，请继续往下看。

二保存 HTML 文件

SAVE THE HTML FILE
  1. 第 1 步：获取 HTML 代码

    点击上方「下载 550W.html 文件」按钮直接下载完整文件；或访问 550W 在线版 后在浏览器右键 → 查看网页源代码 → 全选复制。完整代码以 <!DOCTYPE html> 开头，到 </html> 结尾。

  2. 第 2 步：粘贴到记事本

    打开记事本，按 Ctrl + V 粘贴。

  3. 第 3 步：另存为

    点菜单 文件 → 另存为，按下表填写：

    项目填写内容
    文件名550W.html
    保存类型所有文件（关键，不能选"文本文档"）
    保存位置桌面（方便找）
    编码UTF-8

    点 保存。如果保存后文件名变成 550W.html.txt，说明保存类型选错了，删掉重新保存。

三直接打开（最简单）

RUN IT DIRECTLY

双击桌面上的 550W.html，浏览器会打开，你会看到：

  • 47 节点启动动画
  • 右上角有「跳过启动动画」按钮，点一下直接进主界面
功能能不能用
终端对话（help / status / moss 等指令）✅ 能
编程 — JavaScript✅ 能
编程 — Python❌ 不能（浏览器安全限制）
引擎监控✅ 能
训练 MOSS✅ 能

如果你只玩 JavaScript 和终端，到这里就够了。

四让 Python 也能用（可选）

ENABLE PYTHON · LOCAL SERVER

Python 需要本地服务器才能跑，步骤稍微多点。

Windows 用户

  1. 检查有没有 Python：按 Win + R → 输入 cmd → 回车 → 输入 python --version → 回车。显示版本号（如 Python 3.11.5）则跳到第 2 步；显示"不是内部或外部命令"，去 python.org/downloads 下载最新版，安装时必须勾选 ✅ Add Python to PATH，装完关掉黑窗口重新打开再试。
  2. 启动本地服务器：Win + R → cmd → 输入下面两行，回车：
cd Desktop python -m http.server 8000

看到 Serving HTTP on ... 就成功了。⚠️ 这个黑窗口别关，关了服务器就停了。

Mac 用户

  1. 打开「启动台」→ 搜「终端」→ 打开。
  2. 输入以下两行，回车：
cd ~/Desktop python3 -m http.server 8000

看到 Serving HTTP on ... 就成功了。

第 3 步：打开 Chrome 或 Edge，地址栏输入 http://localhost:8000/550W.html 回车。这样 Python 就能用了。

五怎么确认 Python 好了

VERIFY PYTHON

顶部导航点 「编程」 → 语言下拉选 Python → 右侧终端里会看到加载日志：

[时间] [1/4] 尝试 fastly.jsdelivr.net ...
[时间] ✔ 从 fastly.jsdelivr.net 加载成功！

看到 ✔ 就说明好了。首次加载约 10–20 秒，之后浏览器会缓存。

六运行春节十二响

SPRING FESTIVAL 12 SHOTS
  1. 步骤

    顶部导航点 「编程」 → 右上角语言选 JavaScript → 编辑器里全选（Ctrl+A）删掉 → 粘贴下方代码 → 点左下角 「编译执行」。

  2. 示例代码（可直接运行） 
    // 春节十二响 · 550W 风格演示（JS 模式运行）
const shots = [
  '初始化 6 条', '端口扫描 7 行', '密码破解 4 段', '防火墙穿透 14 行',
  '载荷注入 10 行', '点火', '点火', '点火', '点火', '点火', '点火', '点火',
  '点火', '点火', '点火', '点火', '点火', '点火'
];
const wait = ms => new Promise(r => setTimeout(r, ms));
(async () => {
  for (let i = 0; i < shots.length; i++) {
    console.log(`[${String(i + 1).padStart(2, '0')}] ${shots[i]} ✦`);
    await wait(350);
  }
  console.log('春节十二响完成 — 550W 祝全体地球人新年快乐 ✦');
})();

你会看到终端逐行刷出进度与火花 ✦，全程约 12 秒。

七常见问题

FAQ
双击打开后白屏 / 什么都没有？
换 Chrome 或 Edge；按 F12 看 Console 有没有红色错误，截图排查。
编程视图里编辑器空白？
编辑器会自动尝试 3 个 CDN 源（jsDelivr → Cloudflare → unpkg）加载，某个源被屏蔽会 12 秒内自动换源，一般无需手动操作。若三个源都加载失败（终端日志显示「所有 CDN 源均加载失败」），才是网络整体不通，请刷新页面重试或换个网络环境。
终端输入框打不了字？
点一下终端区域任意位置，再试。
Python 一直加载失败？
确认地址栏是 http://localhost:8000/... 而不是 file:///...；确认黑窗口（服务器）没关；试试换网络环境（有些公司/学校网络会屏蔽 CDN）。
快捷按钮点了没反应？
先点「跳过启动动画」，或者等 4 秒让启动日志跑完。
想换主题 / 语音？
顶栏右侧：◐ 切换主题（红 / 琥珀 / 青）；🔊 开关语音（MOSS 回答会朗读）；⛶ 全屏。

550W 综合指挥系统 · 部署教程

本教程面向「联合政府个人身份管理系统」的完整部署链路：指挥终端（前端）托管于 GitHub Pages，550W 量子主机（云端数据库）使用 Supabase，实现跨设备身份档案、权限、广播与地下城调度的实时互通。全程约 15 分钟即可完成上线。

VERSION 1.0 · 联合政府移山计划总部 · 信息化建设处

二、部署步骤

DEPLOYMENT PROCEDURE
  1. 准备 GitHub 仓库并开启 Pages
    STEP 01 · REPOSITORY & PAGES

    在 GitHub 创建仓库（如 official-site），进入 Settings → Pages，将 Build and deployment 的 Source 设为 Deploy from a branch，分支选 main、目录选 / (root)，保存后等待分配 Pages 域名。

    Pages 域名生成后即为固定网址，勿再更换——本系统所有入口与卡片均引用该域名。

  2. 上传指挥终端（system.html）
    STEP 02 · UPLOAD FRONTEND

    进入仓库页面，点击 Add file → Upload files，将 system.html（单文件自包含，图片已内嵌 Base64）拖入上传区，填写提交说明后点击 Commit changes。

    # 提交后出现以下页面即表示上传成功
Processing your files…  ✓ 已受理

# 1-5 分钟后 Pages 缓存刷新，可用强刷参数核验
https://xiaojiang269.github.io/official-site/system.html?v=1
  3. 初始化 550W 量子主机（Supabase）
    STEP 03 · CLOUD DATABASE

    登录 Supabase 控制台 → 新建项目 → SQL Editor 执行建表语句：

    create table if not exists public.ueg_kv (
  key text primary key,
  value jsonb,
  updated_at timestamptz default now()
);
alter table public.ueg_kv enable row level security;
create policy "anon read" on public.ueg_kv for select using (true);
create policy "anon upsert" on public.ueg_kv for insert
  with check (true) on conflict (key) do update;

    随后在 Settings → API 中获取项目 URL 与 publishable key，写入前端 SUPA_URL / SUPA_KEY 配置常量（云端 key：accounts / settings / broadcasts / navstate）。

  4. 权限初始化与账号核验
    STEP 04 · AUTHORIZATION

    系统内置最高权限档案 周明远 / ZMY：Ⅴ 级最高权限，数字生命管理、系统管理、联合政府管理员后台全权开通；管理员后台仅限管理员账号进入，8 大子系统全部按钮可实际操作。

    # 云端核验账号库（任取其一）
curl -sS -H "apikey: <KEY>" -H "Authorization: Bearer <KEY>" \
  "https://<PROJECT>.supabase.co/rest/v1/ueg_kv?key=eq.accounts&select=value"
  5. 上线验证
    STEP 05 · VERIFICATION

    部署完成后按以下清单逐项验证，全部通过即上线成功：

    验证项方法预期结果
    前端可访问访问固定网址 + ?v=n 强刷登录页正常显示，无平台水印
    云端连通登录后查看顶栏显示「在线模式 · 已同步」
    多设备互通两台设备先后登录同一账号档案/权限/广播实时一致
    权限隔离普通公民访问管理模块拦截提示「仅限联合政府管理员访问」
    raw 源核验raw.githubusercontent.com/…/main/system.html内容与本地发布版一致

三、日常运维手册

OPERATIONS HANDBOOK
数据备份云端快照

用 SQL 导出 ueg_kv 全表；关键 key（accounts）建议每周备份一次，恢复时直接 upsert 覆盖。

健康检查云端核验

curl REST 接口拉取 accounts / broadcasts / navstate，核对关键账号字段、广播条数与导航开关状态。

缓存管理强刷发布

Pages 缓存 1–5 分钟；发布后用 ?v=<递增数字> 访问避免读到旧版，raw 源可先行确认 commit。

异常修复档案纠偏

账号名/权限/地下城异常时，直接改云端 accounts 对应字段（管理员调整后目标账号登录即时生效）。

注意：单文件前端无法直连外部服务器，"在线模式"为界面模拟联动，真实数据存储在 550W 量子主机（Supabase）与本地浏览器；系统不上传任何水印，产物完全自主可控。
